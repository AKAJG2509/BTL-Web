# Đề xuất dự án Bill Pro

## Bối cảnh
Doanh nghiệp nhỏ thường theo dõi hóa đơn bằng bảng tính, dễ bỏ sót hạn thanh toán và khó tổng hợp công nợ.

## Mục tiêu
Xây dựng nguyên mẫu Frontend hỗ trợ theo dõi hóa đơn, khách hàng, thanh toán, nhắc hạn và dự báo dòng tiền từ dữ liệu mô phỏng.

## Vai trò
- Kế toán: quản lý hóa đơn và đối chiếu.
- Kinh doanh: theo dõi công nợ và nhắc thanh toán.
- Quản lý: xem dashboard, hóa đơn quá hạn và dự báo.
- Quản trị viên: quản lý khách hàng, người dùng demo và cấu hình.

## Công nghệ
HTML semantic, CSS responsive, JavaScript DOM/events, dữ liệu JSON và LocalStorage.

## Giới hạn
Không có backend hay dữ liệu ngân hàng thật. Các tính năng AI là mô phỏng JavaScript.
