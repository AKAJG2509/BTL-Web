# Luồng người dùng khởi đầu

## Kế toán
Dashboard → Danh sách hóa đơn → Tạo hóa đơn → Kiểm tra dữ liệu → Lưu → Đối chiếu khi nhận tiền.

## Kinh doanh
Công nợ khách hàng → Chọn hóa đơn/khách hàng → Soạn lời nhắc → Sửa nội dung → Lưu bản nháp → Đánh dấu đã gửi (mô phỏng).

## Quản lý
Dashboard công nợ → Xem hóa đơn quá hạn → Dự báo dòng tiền → Đọc giải thích → Lưu tóm tắt.

## Quản trị viên
Quản lý khách hàng/người dùng/cấu hình → Thêm hoặc chỉnh sửa → Kiểm tra hợp lệ → Lưu.
